# PawnExtensions

Common things to do to a player's hero: hold them in place and kill them. With `using DeadworksManaged.Api.Utils;` they're available on every [`CCitadelPlayerPawn`](/api-reference/entities/ccitadelplayerpawn).


## Methods

### PawnExtensions.Freeze() {#freeze}

Holds the hero in place. Until the freeze ends the player can only look around: they can't move, jump, dash, shoot or use abilities. With `invulnerable`, which is the default, weapons and abilities can't hurt them either. `Kill` still works on a frozen hero.

**Signature**

```csharp
public bool Freeze(float? duration = null, bool invulnerable = true)
```

**Parameters**

- `duration`: Seconds until the freeze wears off by itself. Leave it out to freeze until `Unfreeze`.
- `invulnerable`: Also protect the hero from damage for the same time.

**Returns**
False if the game couldn't apply the freeze.

### PawnExtensions.Kill() {#kill}

Kills the hero. The damage skips resistances and protection, so it works even on an invulnerable hero, and the game treats it as an ordinary death: they wait out the usual death timer unless you pass `respawnImmediately`. A freeze from `Freeze` is lifted first, so they don't come back frozen.

**Signature**

```csharp
public bool Kill(bool respawnImmediately = false)
```

**Parameters**

- `respawnImmediately`: Bring the hero straight back instead of making them wait.

**Returns**
True if the hero was killed.
