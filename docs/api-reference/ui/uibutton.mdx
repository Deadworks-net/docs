### UIButton.TextLabel() {#textlabel}

The Label carrying this button's text, created on first use.

A Button with text and no children has its Label created client-side, where a plugin cannot reach it to apply styles. Asking for the label here moves the text into a real child node instead, which then styles like any other. Idempotent, so repeated calls keep returning the same Label.

**Signature**


### UIButton.CopyOnClick() {#copyonclick}

Make clicking this button copy `text` to the player's clipboard, such as a link to share. The copy happens in the player's game: no event reaches the plugin. Replaces any `OnClick` event.
