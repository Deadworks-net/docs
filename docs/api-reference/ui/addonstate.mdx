# AddonState

What happened to a runtime addon on one client — see [`UI.Addon`](/api-reference/ui/ui#addon).

`Loaded` and `Ready` are deliberately separate: a correctly mounted VPK whose script throws reports Loaded and never reaches Ready, and that is exactly the case worth being able to tell apart.
