# ContentAddons

The content addons connecting clients are told to download.

The active list is the server config's `serverbrowser.content_addons` merged with whatever every loaded plugin declares through `IDeadworksPlugin.ContentAddons`, de-duplicated and kept in that order. Declaring an addon from a plugin means it no longer has to be listed in the server config ahead of time - loading the plugin is enough.

## Methods

### ContentAddons.Refresh() {#refresh}

Re-reads `IDeadworksPlugin.ContentAddons` from every loaded plugin and re-applies the merged list. Plugins are queried automatically when they load and unload, so this is only needed when a plugin's own list changes while it is running.
