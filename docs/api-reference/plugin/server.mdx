### Server.IsChangingLevel {#ischanginglevel}

True while the map is changing, until the next map's `IDeadworksPlugin.OnStartupServer`. It turns on at `ChangeLevel`, or for a change started elsewhere, such as `changelevel` in the server console, once the current map starts shutting down, which is before every player gets a disconnect event with [`ClientDisconnectedEvent.IsMapChange`](/api-reference/events/clientdisconnectedevent#ismapchange). Anything done to players, pawns or panels meanwhile is lost with the old map. If the change fails, such as for a map that doesn't exist, it turns off again after a few seconds.

**Signature**
