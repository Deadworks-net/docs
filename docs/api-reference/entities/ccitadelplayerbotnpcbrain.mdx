## Notes

With [`Bots.AiEnabled`](/api-reference/navigation/bots#aienabled) on, the brain moves the hero itself and may drop a [`CAI_BaseNPC.MoveTo`](/api-reference/entities/cai_basenpc#moveto) order for its own plans, such as a zipline. With it off, call `ApplyMovement` to walk the hero along the brain's path.

## Methods

### CCitadelPlayerBotNPCBrain.ApplyMovement() {#applymovement}

Fills in a usercmd that walks the bot along its brain's path. Returns false, leaving the usercmd alone, if the brain has nowhere to go.

**Signature**

```csharp
public bool ApplyMovement(CCitadelUserCmdPB usercmd, Vector3? lookAt = null)
```

**Parameters**

- `usercmd`: Usercmd to fill in.
- `lookAt`: Point to aim at while moving. Null faces the direction of travel.

**Notes**
Call on each of the bot's usercmds in `IDeadworksPlugin.OnProcessUsercmds`, with [`Bots.AiEnabled`](/api-reference/navigation/bots#aienabled) off, after [`CAI_BaseNPC.MoveTo`](/api-reference/entities/cai_basenpc#moveto). The first usercmd after `MoveTo` also returns false: treat only several false results in a row as arrival. The bot stops about 50 units from the goal.
