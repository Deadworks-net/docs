# CCitadelPlayerBotNPCBrain

The brain of a bot hero (`npc_player_bot_brain`): a hidden NPC that plans the hero's movement and schedules. Get it from [`CCitadelPlayerPawn.BotBrain`](/api-reference/entities/ccitadelplayerpawn#botbrain).

## Notes

While [`Bots.AiEnabled`](/api-reference/navigation/bots#aienabled) is on, the brain drives the hero itself and may drop a [`CAI_BaseNPC.MoveTo`](/api-reference/entities/cai_basenpc#moveto) order for its own plans, such as a zipline. While it is off, the brain still plans the path; `ApplyMovement` walks the hero along it.

## Methods

### CCitadelPlayerBotNPCBrain.ApplyMovement() {#applymovement}

Fills in a usercmd to walk the bot along its brain's path. Returns false, leaving the usercmd alone, if the brain has nowhere to go.

**Signature**

```csharp
public bool ApplyMovement(CCitadelUserCmdPB usercmd, Vector3? lookAt = null)
```

**Parameters**

- `usercmd`: The usercmd to fill in.
- `lookAt`: A point to aim at while moving. Null aims where it is going.

**Notes**
Call from `IDeadworksPlugin.OnProcessUsercmds` on each of the bot's usercmds while [`Bots.AiEnabled`](/api-reference/navigation/bots#aienabled) is off, after [`CAI_BaseNPC.MoveTo`](/api-reference/entities/cai_basenpc#moveto). The brain starts moving on its next think, so the first usercmd after the order returns false; only a run of false results means the bot has arrived or given up. The bot stops about 50 units from the goal.
