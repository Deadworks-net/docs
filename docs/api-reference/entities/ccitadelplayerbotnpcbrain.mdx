# CCitadelPlayerBotNPCBrain

The brain of a bot hero (`npc_player_bot_brain`): an invisible NPC that follows the hero around and owns its navigator and schedules. Get it from [`CCitadelPlayerPawn.BotBrain`](/api-reference/entities/ccitadelplayerpawn#botbrain).

## Notes

[`CAI_BaseNPC.MoveTo`](/api-reference/entities/cai_basenpc#moveto) paths the bot to a point with the game's own pathfinder, and [`CAI_BaseNPC.Schedule`](/api-reference/entities/cai_basenpc#schedule) shows what it is doing.

Whether the brain's decisions reach the hero depends on [`Bots.AiEnabled`](/api-reference/navigation/bots#aienabled). While it is on, the brain turns its navigation into the bot's input itself and also fights. It keeps making its own decisions, so a [`CAI_BaseNPC.MoveTo`](/api-reference/entities/cai_basenpc#moveto) order may be dropped for a zipline or a lane push a moment later. While it is off (the default on a community server) the game sends the bot blank input and ignores the brain: the brain still plans a [`CAI_BaseNPC.MoveTo`](/api-reference/entities/cai_basenpc#moveto) path, and `ApplyMovement` is what walks the hero along it, running at the hero's normal speed and stopping within about 50 units of the goal.

## Methods

### CCitadelPlayerBotNPCBrain.ApplyMovement() {#applymovement}

Walks the bot along the path its brain is following, by filling in a usercmd with the game's own bot movement step. Call it from `IDeadworksPlugin.OnProcessUsercmds` for the bot's slot, on every usercmd, while [`Bots.AiEnabled`](/api-reference/navigation/bots#aienabled) is off. Returns false when the brain has nowhere to go, in which case the usercmd is left alone.

**Signature**

```csharp
public bool ApplyMovement(CCitadelUserCmdPB usercmd, Vector3? lookAt = null)
```

**Parameters**

- `usercmd`: The usercmd to fill in: movement, view angles and buttons.
- `lookAt`: A point for the bot to look at while it moves, so it strafes or backpedals to keep facing it. Null looks where it is going.

**Notes**
Give the brain somewhere to go first with [`CAI_BaseNPC.MoveTo`](/api-reference/entities/cai_basenpc#moveto); once it arrives this returns false again. The bot runs towards each waypoint. Don't call it while [`Bots.AiEnabled`](/api-reference/navigation/bots#aienabled) is on: the brain already sends its own input then.
