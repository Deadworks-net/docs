# SchemaAccessor&lt;T>

Reads and writes a single networked schema field of type `T`. Resolves the field offset once on first access and caches it. Use UTF-8 string literals (`"ClassName"u8`) for `className` and `fieldName`.

```csharp
public sealed class SchemaAccessor<T> where T : unmanaged
```

**Namespace:** `DeadworksManaged.Api`  
**Source:** [Entities/SchemaAccessor.cs#L12](https://github.com/Deadworks-net/deadworks/blob/f62cc7cc/managed/DeadworksManaged.Api/Entities/SchemaAccessor.cs#L12)

## Notes

DeadworksManaged.Game has a generated, typed member for every schema field of every class, so most plugins do not need to declare one of these: `pawn.Schema.m_flRespawnTime`.
