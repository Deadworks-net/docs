# CCollisionProperty

An entity's bounds and collision settings: what it collides with, what traces hit it, and its physics shape. Get it with [`CBaseEntity.Collision`](/api-reference/entities/cbaseentity#collision).

## Notes

Two things collide when either one's `InteractsWith` overlaps the other's `InteractsAs`, unless either one's `InteractsExclude` overlaps the other's `InteractsAs`.

### CCollisionProperty.AddInteractsExclude() {#addinteractsexclude}

Adds `layers` to `InteractsExclude`, so nothing on those layers collides with the entity.

**Signature**

```csharp
public void AddInteractsExclude(InteractionLayer layers)
```

**Example**
Let shots pass through a prop that players still collide with:

```csharp
prop.Collision?.AddInteractsExclude(InteractionLayer.CitadelBullet | InteractionLayer.CitadelAbility);
```

**Notes**
Takes effect immediately and survives [`CBaseEntity.SetModel`](/api-reference/entities/cbaseentity#setmodel). Call it after the entity spawns. On heroes and other units, the game resets the team, bullet and ability layers whenever it sets their team.
