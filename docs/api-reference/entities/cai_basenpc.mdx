### CAI_BaseNPC.MoveTo() {#moveto}

Sends the NPC to a point, like `npc_go`.

**Signature**

```csharp
public void MoveTo(Vector3 goal, bool run = true, float tolerance = 0f)
```

**Parameters**

- `goal`: Destination. Need not be on the navmesh.
- `run`: Run instead of walking.
- `tolerance`: Arrival distance. 0 uses the `npc_go` default.

**Notes**
The NPC ignores enemies and damage until it arrives or the path fails, then resumes its own AI. Most orders over 3000 units of path fail. Shorter ones can stop partway in `SCHED_FAIL`. Send long trips in legs along [`Nav.FindPath`](/api-reference/navigation/nav#findpath), and order again after a failure. To follow a moving target, call again every 0.5 s.
