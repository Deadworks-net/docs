### CAI_BaseNPC.Create() {#create}

Creates and spawns an NPC by its VData subclass name, such as `neutral_trooper_strong` or `npc_boss_tier1`. Returns null if the name is not an NPC subclass.

**Signature**

```csharp
public static CAI_BaseNPC? Create(string designerName, Vector3 position, int team = 0, Vector3? angles = null)
```

**Parameters**

- `designerName`: The subclass name. `SubclassNames` in DeadworksManaged.Game lists them.
- `position`: Where the NPC appears.
- `team`: 0 keeps the NPC's default team.
- `angles`: Pitch, yaw, roll. Null faces +X.

**Notes**
A class name such as `npc_trooper_neutral` returns null: an NPC without VData crashes the server. For lane troopers use [`CNPC_Trooper.Create`](/api-reference/entities/cnpc_trooper#create), which also assigns a lane.

### CAI_BaseNPC.MoveTo() {#moveto}

Sends the NPC to `goal`, as `npc_go` does, without cheats.

**Signature**

```csharp
public void MoveTo(Vector3 goal, bool run = true, float tolerance = 0f)
```

**Parameters**

- `goal`: Where to go.
- `run`: Run instead of walking.
- `tolerance`: How close counts as arrived. 0 matches `npc_go`.

**Notes**
The NPC ignores enemies and damage until it arrives or the path fails, unless `npc_go_allow_interrupt_by_ai_conditions` is on. It then resumes its own behaviour. Most orders more than 3000 units of path away fail, and nearer ones can fail partway: the NPC stops and runs `SCHED_FAIL`. Order a long trip in legs along [`Nav.FindPath`](/api-reference/navigation/nav#findpath), and order again after a failure. To follow a moving target, call this again every half second. The goal need not be on the navmesh.

### CAI_BaseNPC.SetSchedule() {#setschedule}

Starts the named schedule, such as `SCHED_IDLE_STAND`. Returns false if the NPC refuses it.

**Signature**

```csharp

```

**Notes**
The schedule runs until it finishes or is interrupted, then the NPC picks its next one; `IDeadworksPlugin.OnNpcSelectSchedule` can replace that choice. A schedule the NPC's class does not have runs `SCHED_IDLE_STAND` and logs "No CASE for Schedule Type".
