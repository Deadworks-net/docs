# CCitadelZiplinePath

A lane's zipline rope (`citadel_zipline_path`). A map's ropes tell you which lanes it has:

```csharp

    .Select(rope => rope.Lane)
    .Where(lane => lane != LaneColor.Invalid)
    .ToHashSet();
```
