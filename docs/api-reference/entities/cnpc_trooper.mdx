## Notes

The game recycles troopers. Before the first wave it spawns hidden ones and keeps them dormant (see [`CAI_BaseNPC.IsDormant`](/api-reference/entities/cai_basenpc#isdormant)), and new spawns reuse them, so a trooper you stored earlier can come back as a different spawn, possibly on another team or lane.
