## Notes

The game recycles troopers. Before the first wave it spawns hidden ones and keeps them dormant (see [`CAI_BaseNPC.IsDormant`](/api-reference/entities/cai_basenpc#isdormant)), and new spawns reuse them, so a trooper you stored earlier can come back as a different spawn, possibly on another team or lane.

## Methods

### CNPC_Trooper.Create() {#create}

Spawns a trooper the way `citadel_spawn_trooper` does, with no cheats needed. Returns it, or null if it could not be spawned.

**Signature**

```csharp
public static CNPC_Trooper? Create(Vector3 position, int team, TrooperType type = TrooperType.Normal, Vector3? angles = null, bool snapToGround = true)
```

**Parameters**

- `position`: Where the trooper appears.
- `team`: The team number (2 Amber, 3 Sapphire).
- `type`: Which kind of trooper.
- `angles`: The way it faces (pitch, yaw, roll). Null faces along +X.
- `snapToGround`: Drop it onto the ground below `position`.

**Notes**
The trooper joins the lane nearest to `position` and walks it like a wave trooper. A dormant pooled trooper of the same type is reused when one is free, so the returned entity can be one that existed before.
