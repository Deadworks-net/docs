## Notes

The game reuses troopers: hidden ones wait [`CAI_BaseNPC.IsDormant`](/api-reference/entities/cai_basenpc#isdormant) and come back as new spawns. A stored trooper can return as a different spawn, on another team or lane.

### CNPC_Trooper.Create() {#create}

Spawns a trooper, as `citadel_spawn_trooper` does, without cheats. Returns null if it could not be spawned.

**Signature**

```csharp
public static CNPC_Trooper? Create(Vector3 position, int team, TrooperType type = TrooperType.Normal, Vector3? angles = null, bool snapToGround = true)
```

**Parameters**

- `position`: Where the trooper appears.
- `team`: 2 Amber, 3 Sapphire.
- `type`: The kind of trooper.
- `angles`: Pitch, yaw, roll. Null faces +X.
- `snapToGround`: Drop it onto the ground below `position`.

**Notes**
The trooper joins the lane nearest `position` and walks it. A free dormant trooper of the same type is reused if there is one.
