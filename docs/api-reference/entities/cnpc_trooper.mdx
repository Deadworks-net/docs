## Notes

The game pools troopers: hidden ones are [`CAI_BaseNPC.IsDormant`](/api-reference/entities/cai_basenpc#isdormant) and come back as new spawns, possibly on another team or lane. A stored reference can become a different trooper.

### CNPC_Trooper.Create() {#create}

Spawns a lane trooper, like `citadel_spawn_trooper`. Returns null on failure.

**Signature**

```csharp
public static CNPC_Trooper? Create(Vector3 position, int team, TrooperType type = TrooperType.Normal, Vector3? angles = null, bool snapToGround = true)
```

**Parameters**

- `position`: Spawn position.
- `team`: 2 Amber, 3 Sapphire.
- `type`: Trooper type.
- `angles`: Pitch, yaw, roll. Null faces +X.
- `snapToGround`: Drop it to the ground below `position`.

**Notes**
The trooper joins the lane nearest `position`. A free pooled trooper of the same type is reused.
