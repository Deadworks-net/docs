# API Reference

Every public type in `DeadworksManaged.Api`, generated from the Deadworks source at commit [`2ed5cbf`](https://github.com/Deadworks-net/deadworks/tree/2ed5cbf2f1af4a372b0c6dd1eb17e64633f09e61). Each member lists its signature and a link to its source. If you're new to Deadworks, start with the [Features](/features/commands) pages instead; they show how to do common things.

## Commands

| Type | Description |
|------|-------------|
| [`Caller`](/api-reference/commands/caller) | Who ran a command: a player, or the server console (which includes rcon). Take it as the first parameter of a [`CommandAttribute`](/api-reference/commands/commandattribute) method. Unlike a nullable controller, the console is explicit here, so a failed player lookup can never be mistaken for it. |
| [`CommandAttribute`](/api-reference/commands/commandattribute) | Registers a method as `/name`, `!name`, and `dw_name` with typed parameter binding. |
| [`CommandConverters`](/api-reference/commands/commandconverters) | Per-type string parsers for [`CommandAttribute`](/api-reference/commands/commandattribute) parameters, for types Deadworks doesn't parse itself. Register from `OnLoad`; a plugin's converters are dropped automatically when it unloads. A parser may throw [`CommandException`](/api-reference/commands/commandexception) to tell the caller what's wrong with their input; anything else shows the usage line. A converter applies to every plugin's commands, so prefer registering one for your own types; one for a shared type such as `TimeSpan` replaces any other plugin's. |
| [`CommandException`](/api-reference/commands/commandexception) | Thrown from a [`CommandAttribute`](/api-reference/commands/commandattribute) handler, or a [`CommandConverters`](/api-reference/commands/commandconverters) parser, to stop the command and send `Exception.Message` to the caller. Nothing is logged: it's an answer, not an error. Any other exception is logged with its stack trace, and the caller only hears that the command failed. |
| [`Target`](/api-reference/commands/target) | Players picked by a [`CommandAttribute`](/api-reference/commands/commandattribute) argument. Accepts `@me`, `@all`, `@team`, `@enemy`, `#slot`, a SteamID (64, Steam2 or Steam3), or part of a player's name. Players the caller can't target are left out according to [`CommandAttribute.TargetImmunity`](/api-reference/commands/commandattribute#targetimmunity). Never empty: a pattern that matches nobody is a usage error before the command runs. |
| [`TargetImmunity`](/api-reference/commands/targetimmunity) | Whether a command's [`Target`](/api-reference/commands/target) parameters skip players the caller can't target. |
