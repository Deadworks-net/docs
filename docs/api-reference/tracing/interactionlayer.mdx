# InteractionLayer

Interaction layers, combined with `|`. An object belongs to layers ([`CCollisionProperty.InteractsAs`](/api-reference/entities/ccollisionproperty#interactsas)), collides with layers ([`CCollisionProperty.InteractsWith`](/api-reference/entities/ccollisionproperty#interactswith)) and can exclude layers ([`CCollisionProperty.InteractsExclude`](/api-reference/entities/ccollisionproperty#interactsexclude)).
