## Methods

### Bots.Add() {#add}

Adds a bot hero, like `citadel_create_unit`. Returns its pawn, or null if bots can't play the hero, the server is full or no map is loaded.

**Signature**

```csharp
public static CCitadelPlayerPawn? Add(Heroes? hero, int team, Vector3 position, BotDifficulty? difficulty = null, bool assignLane = true)
```

**Parameters**

- `hero`: Hero. Null picks a random one.
- `team`: 2 Amber, 3 Sapphire.
- `position`: Spawn position, on the navmesh.
- `difficulty`: Null uses `citadel_default_bot_difficulty`.
- `assignLane`: Let the game pick a lane.

**Notes**
The bot joins as a fake client named `BotN`. Its hero finishes loading shortly after; wait before reading its abilities. Remove it with [`Server.Kick`](/api-reference/plugin/server#kick). It only plays while `AiEnabled` is on.

**Source:** [Bots.cs#L22](https://github.com/Deadworks-net/deadworks/blob/65bce38d/managed/DeadworksManaged.Api/Bots.cs#L22)

### Bots.SetMoveInput() {#setmoveinput}

Fills in a usercmd that moves a bot hero towards a point. Call from `IDeadworksPlugin.OnProcessUsercmds` while `AiEnabled` is off.

**Parameters**

- `usercmd`: The bot's usercmd.
- `pawn`: The bot hero.
- `moveTo`: Point to move towards. Height is ignored.
- `lookAt`: Point to aim at while moving. Null faces the direction of travel.
- `jump`: Press jump.
