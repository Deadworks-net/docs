## Notes

Add one with `Add`, which goes through the game's own bot creation: the hero is loaded, the bot AI attached and a lane picked the way practice bots get theirs. A fake client from [`Server.CreateFakeClient`](/api-reference/plugin/server#createfakeclient) also gets bot AI attached, but no hero until a plugin gives it one.

## Properties

### Bots.AiEnabled {#aienabled}

Whether bot heroes play on their own: take ziplines, push their lane, fight. Off by default on a server with no matchmaking lobby, where the game treats bots as inert dummies and sends them blank input.

**Signature**


**Notes**

## Methods

### Bots.Add() {#add}

Adds a bot hero, the way `citadel_create_unit` does. Returns its pawn, or null when the hero is not allowed for bots in this build, the server is full, or no map is loaded (the game logs which).

**Signature**

```csharp
public static CCitadelPlayerPawn? Add(Heroes? hero, int team, Vector3 position, BotDifficulty? difficulty = null, bool assignLane = true)
```

**Parameters**

- `hero`: The hero to play, or null for a random one bots are allowed to play.
- `team`: The team number (2 Amber, 3 Sapphire).
- `position`: Where the hero appears. Use a point on the navmesh, such as one from [`Nav.GetNearestPoint`](/api-reference/navigation/nav#getnearestpoint), and not in the enemy base, which kills it within seconds.
- `difficulty`: How well it plays. Null uses `citadel_default_bot_difficulty`.
- `assignLane`: Let the game pick its lane, as for practice bots. Set one yourself with [`CCitadelPlayerPawn.SetBotLane`](/api-reference/entities/ccitadelplayerpawn#setbotlane).

**Notes**
The bot is a fake client named `BotN`. It joins `team` at `position`; the hero finishes loading a moment later, so wait before reading its abilities. Remove it with [`Server.Kick`](/api-reference/plugin/server#kick).

Whether it then plays on its own depends on `AiEnabled`, off by default on a community server.

**Source:** [Bots.cs#L37](https://github.com/Deadworks-net/deadworks/blob/f62cc7cc/managed/DeadworksManaged.Api/Bots.cs#L37)

### Bots.SetMoveInput() {#setmoveinput}

Fills in a usercmd so a bot hero moves towards `moveTo`: forwardmove and leftmove, view angles and the matching movement keys. Use it from `IDeadworksPlugin.OnProcessUsercmds` to drive a bot with your own steering, for example along a [`NavPathFollower`](/api-reference/navigation/navpathfollower), while `AiEnabled` is off. To follow the brain's own path instead, use [`CCitadelPlayerBotNPCBrain.ApplyMovement`](/api-reference/entities/ccitadelplayerbotnpcbrain#applymovement).

**Signature**

```csharp
public static void SetMoveInput(CCitadelUserCmdPB usercmd, CCitadelPlayerPawn pawn, Vector3 moveTo, Vector3? lookAt = null, bool jump = false)
```

**Parameters**

- `usercmd`: The bot's usercmd.
- `pawn`: The bot hero.
- `moveTo`: The point to move towards. Height is ignored.
- `lookAt`: A point to keep looking at while moving (it strafes or backpedals). Null looks where it is going.
- `jump`: Press jump this command, for example when [`NavPathFollower.ShouldJump`](/api-reference/navigation/navpathfollower#shouldjump).

**Source:** [Bots.cs#L72](https://github.com/Deadworks-net/deadworks/blob/f62cc7cc/managed/DeadworksManaged.Api/Bots.cs#L72)
