## Methods

### Bots.Add() {#add}

Adds a bot hero, as `citadel_create_unit` does. Returns its pawn, or null if bots cannot play the hero, the server is full or no map is loaded.

**Signature**

```csharp
public static CCitadelPlayerPawn? Add(Heroes? hero, int team, Vector3 position, BotDifficulty? difficulty = null, bool assignLane = true)
```

**Parameters**

- `hero`: The hero. Null picks a random one.
- `team`: 2 Amber, 3 Sapphire.
- `position`: Where the hero appears. Use a point on the navmesh, not in the enemy base.
- `difficulty`: Null uses `citadel_default_bot_difficulty`.
- `assignLane`: Let the game pick a lane, as for practice bots.

**Notes**
The bot is a fake client named `BotN`. Its hero finishes loading a moment later; wait before reading its abilities. Remove it with [`Server.Kick`](/api-reference/plugin/server#kick). It plays on its own only while `AiEnabled` is on.

**Source:** [Bots.cs#L24](https://github.com/Deadworks-net/deadworks/blob/f7f2cba2/managed/DeadworksManaged.Api/Bots.cs#L24)

### Bots.SetMoveInput() {#setmoveinput}

**Parameters**

- `usercmd`: The bot's usercmd.
- `pawn`: The bot hero.
- `moveTo`: The point to move towards. Height is ignored.
- `lookAt`: A point to aim at while moving. Null aims where it is going.
