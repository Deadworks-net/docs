# Nav

Queries on the navmesh, the walkable surface NPCs path over. No NPC is needed.

## Notes

The navmesh is generated per hull, a body size: an area one hull crosses may not exist for another. Heroes use hull 0, lane troopers hull 1. Out-of-range hulls are treated as hull 0. Without a navmesh every query returns null.

### Nav.Raycast() {#raycast}

Traces a straight line along the navmesh from `start` to `end`. Returns true if it stays on the walkable surface.

**Signature**


**Parameters**

- `end`: Where it should reach.
- `stoppedAt`: `end` on the mesh, or the edge the line ran into.

**Notes**

### Nav.FindPath() {#findpath}

Finds a path from `start` to `goal` with the game's pathfinder. Returns null if there is none.

**Signature**

```csharp
public static NavPath? FindPath(Vector3 start, Vector3 goal, int hull = 0, bool allowPartial = false, bool simplify = true)
public static NavPath? FindPath(Vector3 start, Vector3 goal, CBaseEntity walker, bool allowPartial = false, bool simplify = true)
```

**Parameters**

- `start`: Where the path starts.
- `goal`: Where it should end.
- `hull`: The navmesh hull to path for.
- `allowPartial`: Accept a path that stops short of the goal. Compare [`NavPath.End`](/api-reference/navigation/navpath#end) with the goal.
- `simplify`: Keep only the corners. Otherwise there is a waypoint per area crossed.

**Notes**
Both ends must be on the navmesh; snap them with `GetNearestPoint`. A path across half the map takes about 1 ms, a failed search of the whole map about 3 ms. The path uses the hull's default cost, so it ignores NPC-specific rules such as a trooper's lane.

### Nav.CreateBlocker() {#createblocker}

Blocks a box of the navmesh with a `script_nav_blocker`. NPCs and `FindPath` route around it. Remove the returned entity to unblock. Returns null if it could not be created.

**Signature**

```csharp
public static CBaseEntity? CreateBlocker(Vector3 center, Vector3 halfExtents, Vector3? angles = null, int team = 0)
```

**Parameters**

- `center`: The middle of the box.
- `halfExtents`: Half the box's size along each axis, before `angles`.
- `angles`: Pitch, yaw, roll. Null is axis-aligned.
- `team`: The only team to block, or 0 to block everyone.

**Notes**
The navmesh updates a moment after the call.
