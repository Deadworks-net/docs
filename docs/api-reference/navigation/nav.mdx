# Nav

Queries on the map's navigation mesh, the walkable surface NPCs path over. Everything here runs the game's own navmesh code and needs no NPC.

```

## Notes

The navmesh is generated per hull, a size class: an area a small hull can cross may not exist for a larger one. Heroes and bots use hull 0 and lane troopers hull 1; `GetHull` reads it from an entity. Out-of-range hulls are treated as hull 0. A map without a navmesh answers every query with null.

### Nav.GetNearestPoint() {#getnearestpoint}

Finds the closest point on the navmesh to `position`, the same way NPCs snap a goal onto the navmesh before they path to it. Returns null when nothing is in range.

**Signature**

```

**Parameters**

- `position`: The point to snap.
- `maxDistance`: How far to search, in units. 10000 is what the game's NPCs use.
- `hull`: The navmesh hull to search.

**Notes**
Use it before [`CAI_BaseNPC.MoveTo`](/api-reference/entities/cai_basenpc#moveto) or `FindPath` when a point might not be walkable, for example one offset from a player, which can land inside a wall or off a ledge. A query costs a few microseconds.

### Nav.Raycast() {#raycast}

Walks a straight line across the navmesh from `start` towards `end`. Returns true if it gets there without leaving the walkable surface, so something of that hull can walk the line directly.

**Signature**

```csharp
public static bool Raycast(Vector3 start, Vector3 end, out Vector3 stoppedAt, int hull = 0)
```

**Parameters**

- `start`: Where the line starts. Moved onto the navmesh first.
- `end`: Where it should reach.
- `stoppedAt`: Where the line stopped: `end` on the mesh, or the edge it ran into.
- `hull`: The navmesh hull to test.

**Notes**
It follows the mesh, not the air above it, and steps or drops of more than 20 units stop it; it does not see nav blockers. A start more than 200 units from the navmesh fails. Cheaper than `FindPath`, so it is the way to check whether a path is needed at all.

### Nav.FindPath() {#findpath}

Finds a walkable path from `start` to `goal` with the game's own navmesh pathfinder. Returns null when there is no path.

**Signature**

```csharp
public static NavPath? FindPath(Vector3 start, Vector3 goal, int hull = 0, bool allowPartial = false, bool simplify = true)
public static NavPath? FindPath(Vector3 start, Vector3 goal, CBaseEntity walker, bool allowPartial = false, bool simplify = true)
```

**Parameters**

- `start`: Where the path starts.
- `goal`: Where it should end.
- `hull`: The navmesh hull to path for.
- `allowPartial`: Also accept a path that stops short of the goal, as far as the pathfinder got towards it. Compare [`NavPath.End`](/api-reference/navigation/navpath#end) with the goal to tell.
- `simplify`: Run the game's path optimizer, which keeps only the corners: each waypoint can be walked to in a straight line from the one before. Without it there is a waypoint for every nav area the path crosses.

**Notes**
Both ends must be on the navmesh: a start in the air, for example, finds no path. Snap a point that might be off it with `GetNearestPoint` first. Hulls differ in where they can go: a point the trooper hull can't reach may be reachable on hull 0.

A query takes about a millisecond for a path across half the map and about three when it searches the whole map and fails, so don't run one per bot every tick; path once and re-path when the goal moves. A path has at most `MaxPathPoints` waypoints.

The path uses the default path cost for the hull, so it ignores things only a particular NPC cares about, such as a trooper's lane. Use it to steer something yourself or to measure walking distance; to move an NPC or a bot, [`CAI_BaseNPC.MoveTo`](/api-reference/entities/cai_basenpc#moveto) already paths for it.

### Nav.CreateBlocker() {#createblocker}

Blocks a box of the navmesh by spawning the game's own `script_nav_blocker` entity: NPCs path around it and `FindPath` routes around it. Remove the returned entity to open the area again. Returns null if the entity could not be created.

**Signature**

```csharp
public static CBaseEntity? CreateBlocker(Vector3 center, Vector3 halfExtents, Vector3? angles = null, int team = 0)
```

**Parameters**

- `center`: The middle of the box.
- `halfExtents`: Half the box's size along each axis, before `angles`.
- `angles`: The box's rotation (pitch, yaw, roll). Null leaves it axis-aligned.
- `team`: The only team to block, or 0 to block everyone.

**Notes**
The navmesh updates a moment after the spawn, not within the same call.
