# Nav

Queries the navmesh, the walkable surface NPCs path over. No NPC is needed.


## Notes

The navmesh is built per hull (body size), so an area one hull can cross may not exist for another. Heroes use hull 0, lane troopers hull 1. Unknown hulls fall back to 0. On a map without a navmesh every query returns null.

### Nav.Raycast() {#raycast}

Traces a straight line across the navmesh. Returns true if it reaches `end` without leaving the walkable surface.

**Signature**

```csharp
public static bool Raycast(Vector3 start, Vector3 end, out Vector3 stoppedAt, int hull = 0)
```

**Parameters**

- `start`: Start point. Snapped onto the navmesh first.
- `end`: End point.
- `stoppedAt`: `end` on the navmesh, or the edge the line ran into.
- `hull`: Navmesh hull.

**Notes**
Steps or drops over 20 units stop it; nav blockers don't. Fails if `start` is more than 200 units from the navmesh. Cheaper than `FindPath`.

### Nav.FindPath() {#findpath}

Finds a path with the game's pathfinder. Returns null if there is none.

**Signature**

```csharp
public static NavPath? FindPath(Vector3 start, Vector3 goal, int hull = 0, bool allowPartial = false, bool simplify = true)
public static NavPath? FindPath(Vector3 start, Vector3 goal, CBaseEntity walker, bool allowPartial = false, bool simplify = true)
```

**Parameters**

- `start`: Start point.
- `goal`: Goal point.
- `hull`: Navmesh hull.
- `allowPartial`: Accept a path that stops short of the goal. Compare [`NavPath.End`](/api-reference/navigation/navpath#end) with the goal.
- `simplify`: Keep only corners. False gives a waypoint per area crossed.

**Notes**
Both ends must be on the navmesh; snap them with `GetNearestPoint`. Takes about 1 ms across half the map, 3 ms for a failed search. Uses the hull's default costs, so it ignores per-NPC rules such as a trooper's lane.

**Source:** [Nav.cs#L272](https://github.com/Deadworks-net/deadworks/blob/65bce38d/managed/DeadworksManaged.Api/Nav.cs#L272), [Nav.cs#L294](https://github.com/Deadworks-net/deadworks/blob/65bce38d/managed/DeadworksManaged.Api/Nav.cs#L294)

### Nav.CreateBlocker() {#createblocker}

Blocks a box of the navmesh with a `script_nav_blocker`. NPCs and `FindPath` route around it. Returns the blocker, or null on failure; remove it to unblock.

**Signature**

```csharp
public static CBaseEntity? CreateBlocker(Vector3 center, Vector3 halfExtents, Vector3? angles = null, int team = 0)
```

**Parameters**

- `center`: Box centre.
- `halfExtents`: Half the box size on each axis, before `angles`.
- `angles`: Pitch, yaw, roll. Null is axis-aligned.
- `team`: Team to block, or 0 for everyone.

**Notes**
Takes effect shortly after the call.
