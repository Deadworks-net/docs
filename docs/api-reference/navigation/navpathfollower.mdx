# NavPathFollower

Tracks progress along a [`NavPath`](/api-reference/navigation/navpath). Call `Update` each tick and steer towards the point it returns with [`Bots.SetMoveInput`](/api-reference/navigation/bots#setmoveinput).

**Source:** [Nav.cs#L50](https://github.com/Deadworks-net/deadworks/blob/65fee60e/managed/DeadworksManaged.Api/Nav.cs#L50)

## Notes

A waypoint counts as reached within `ArriveRadius` on the ground plane, or once passed. The follower doesn't re-path. Find a new path when `DistanceFromPath` grows.
