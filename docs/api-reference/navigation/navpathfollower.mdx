# NavPathFollower

Tracks progress along a [`NavPath`](/api-reference/navigation/navpath). Call `Update` with the current position each tick and steer towards the result, for a bot hero with [`Bots.SetMoveInput`](/api-reference/navigation/bots#setmoveinput).

**Namespace:** `DeadworksManaged.Api`  
**Source:** [Nav.cs#L50](https://github.com/Deadworks-net/deadworks/blob/7da5cd7f/managed/DeadworksManaged.Api/Nav.cs#L50)

## Notes

A waypoint is reached within `ArriveRadius` on the ground plane, or once passed. The follower does not re-path; find a new path when `DistanceFromPath` grows large.
