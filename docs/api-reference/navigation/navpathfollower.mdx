# NavPathFollower

Walks something along a [`NavPath`](/api-reference/navigation/navpath): call `Update` with the current position every tick and steer towards what it returns. For a bot hero, pass that to [`Bots.SetMoveInput`](/api-reference/navigation/bots#setmoveinput).

## Notes

A waypoint counts as reached once the walker is within `ArriveRadius` of it on the ground plane, or has gone past it towards the next one. The follower doesn't re-path: when the walker is pushed far off the route (`DistanceFromPath`), find a new path.
