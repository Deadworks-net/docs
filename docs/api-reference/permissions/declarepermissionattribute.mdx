# DeclarePermissionAttribute

Lists a permission that is only checked in code (with [`PermissionExtensions.HasPermission`](/api-reference/permissions/permissionextensions#haspermission)) in the plugin's generated permissions file, so server owners can find it. Permissions on [`CommandAttribute`](/api-reference/commands/commandattribute) are listed automatically.
