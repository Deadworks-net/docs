# Permissions

Checks against the server's roles and players. Most plugins only need [`CommandAttribute.Permission`](/api-reference/commands/commandattribute#permission) and [`Caller.HasPermission`](/api-reference/commands/caller#haspermission); this class covers offline players and custom stores. A null controller has no permissions: use [`Caller`](/api-reference/commands/caller) for code that runs for the console or a player.

### Permissions.IsLoaded() {#isloaded}

Whether the store's answer for this SteamID has arrived: its entry, or that it has none. Checks by SteamID start loading it; until it arrives they answer as `default`, and `CanTarget` refuses. Always true for the JSON store.
