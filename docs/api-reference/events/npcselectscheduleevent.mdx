### NpcSelectScheduleEvent.Schedule {#schedule}

The schedule the game chose, such as `SCHED_TROOPER_RUN_DOWN_LANE`, or `SCHED_FAIL` after a failure. This is the id before the NPC's class translates it, so it can differ from [`CAI_BaseNPC.Schedule`](/api-reference/entities/cai_basenpc#schedule) once the schedule runs.

### NpcSelectScheduleEvent.Override {#override}

Set to a schedule name to run that instead, for example `SCHED_IDLE_STAND` to keep a trooper where it is. Null keeps the game's choice. With several plugins, the last one to set it wins.

**Signature**

```csharp
public string? Override { get; set; }
```

**Notes**
The name is resolved like the game's own choice. A name the NPC's class has no schedule for runs `SCHED_IDLE_STAND`, and the game logs "No CASE for Schedule Type".
