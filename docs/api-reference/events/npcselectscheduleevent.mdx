### NpcSelectScheduleEvent.Schedule {#schedule}

The schedule the game chose, such as `SCHED_TROOPER_RUN_DOWN_LANE`, or `SCHED_FAIL` after a failure. The NPC's class may translate it, so [`CAI_BaseNPC.Schedule`](/api-reference/entities/cai_basenpc#schedule) can differ once it runs.

### NpcSelectScheduleEvent.Override {#override}

A schedule to run instead, such as `SCHED_IDLE_STAND`. Null keeps the game's choice. The last plugin to set it wins.

**Signature**

```csharp
public string? Override { get; set; }
```

**Notes**
A schedule the NPC's class does not have runs `SCHED_IDLE_STAND` and logs "No CASE for Schedule Type".
