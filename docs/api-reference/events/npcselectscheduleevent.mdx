### NpcSelectScheduleEvent.Schedule {#schedule}

Schedule the game picked, such as `SCHED_TROOPER_RUN_DOWN_LANE`, or `SCHED_FAIL` after a failure. NPC classes rename some schedules, so [`CAI_BaseNPC.Schedule`](/api-reference/entities/cai_basenpc#schedule) can differ once it runs.

### NpcSelectScheduleEvent.Override {#override}

Schedule to run instead, such as `SCHED_IDLE_STAND`. Null keeps the game's pick. The last plugin to set it wins.

**Signature**


**Notes**
A schedule the NPC's class lacks runs `SCHED_IDLE_STAND` and logs "No CASE for Schedule Type".
