# EntityIO

Hooks into the Valve entity I/O system to observe or intercept inputs and outputs. Two symmetric APIs: `HookInput` for `CEntityInstance::AcceptInput`, `HookOutput` for `CEntityIOOutput::FireOutputInternal`.

## Notes

Class and input/output names support `"*"` as a wildcard. Hooks are matched against four keys in priority order: `(class, name)`, `(class, "*")`, `("*", name)`, `("*", "*")`.

Pre-mode handlers return [`HookResult`](/api-reference/enums/hookresult) ([`HookResult.Stop`](/api-reference/enums/hookresult#stop) blocks the original). Post-mode handlers return `void` and run after the original — they cannot block.

### EntityIO.HookInput() {#hookinput}

Subscribes to entity inputs matching `className` + `inputName`. Handler may return [`HookResult.Stop`](/api-reference/enums/hookresult#stop) to block the input.

**Parameters**

- `className`: Receiving entity's designer name, or `"*"`.
- `inputName`: Input name (e.g. `"Kill"`), or `"*"`.
- `handler`: Pre-mode handler. Return [`HookResult.Continue`](/api-reference/enums/hookresult#continue) to let the original run.
- `mode`: When the handler runs. Defaults to [`HookMode.Pre`](/api-reference/enums/hookmode#pre).

**Returns**
A handle that cancels the hook when [`IHandle.Cancel`](/api-reference/timers/ihandle#cancel) is called. Plugin unload also auto-cancels.
