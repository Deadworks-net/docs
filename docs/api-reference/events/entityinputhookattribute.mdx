# EntityInputHookAttribute

Marks a method as an entity-input hook. The method is auto-registered on plugin load and dropped on unload.

```csharp
public sealed class EntityInputHookAttribute : Attribute
```

**Namespace:** `DeadworksManaged.Api`  
**Inherits / implements:** `Attribute`  
**Source:** [Events/EntityInputHookAttribute.cs#L22](https://github.com/Deadworks-net/deadworks/blob/76f73b504d7b811b678d092a1e762a8e08b5d2d9/managed/DeadworksManaged.Api/Events/EntityInputHookAttribute.cs#L22)

## Notes

Pre handlers must return [`HookResult`](/api-reference/enums/hookresult). Post handlers must return `void`. Use `"*"` as a wildcard for either `className` or `inputName`.

## Example

```csharp
[EntityInputHook("func_button", "Kill")]
public HookResult OnKillInput(EntityInputEvent e) {
    return HookResult.Stop;   // veto: button won't kill the activator
}

[EntityInputHook("*", "Toggle", HookMode.Post)]
public void OnToggleObserved(EntityInputEvent e) { /* post: cannot block */ }
```
