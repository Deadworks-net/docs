## Notes

Holds a pointer to the native `variant_t` for the duration of the hook callback. Do not retain an [`EntityIOValue`](/api-reference/events/entityiovalue) past the callback's return — the native pointer becomes invalid. If you need to retain the value, call the typed accessor (e.g. `AsString`) immediately and store the result.
