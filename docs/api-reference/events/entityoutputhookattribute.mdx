# EntityOutputHookAttribute

Marks a method as an entity-output hook. The method is auto-registered on plugin load and dropped on unload.

```csharp
public sealed class EntityOutputHookAttribute : Attribute
```

**Namespace:** `DeadworksManaged.Api`  
**Inherits / implements:** `Attribute`  
**Source:** [Events/EntityOutputHookAttribute.cs#L22](https://github.com/Deadworks-net/deadworks/blob/2ed5cbf2f1af4a372b0c6dd1eb17e64633f09e61/managed/DeadworksManaged.Api/Events/EntityOutputHookAttribute.cs#L22)

## Notes

Pre handlers must return [`HookResult`](/api-reference/enums/hookresult). Post handlers must return `void`. Use `"*"` as a wildcard for either `className` or `outputName`.

## Example

```csharp
[EntityOutputHook("trigger_multiple", "OnStartTouch")]
public HookResult OnTriggerTouched(EntityOutputEvent e) {
    return HookResult.Continue;
}

[EntityOutputHook("*", "OnPlayerPickup", HookMode.Post)]
public void OnAnyPickup(EntityOutputEvent e) { /* observer only */ }
```
