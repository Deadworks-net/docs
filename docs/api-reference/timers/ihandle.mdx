# IHandle

A handle to a cancellable subscription — returned by timers, game-event listeners, net-message hooks, entity I/O hooks, and any other API that registers a long-lived callback. Allows cancellation and status checking.

### IHandle.CancelOnMapChange() {#cancelonmapchange}
