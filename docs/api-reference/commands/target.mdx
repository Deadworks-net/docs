# Target

Players picked by a [`CommandAttribute`](/api-reference/commands/commandattribute) argument. Accepts `@me`, `@all`, `@team`, `@enemy`, `#slot`, a SteamID (64, Steam2 or Steam3), or part of a player's name. Players the caller can't target are left out according to [`CommandAttribute.TargetImmunity`](/api-reference/commands/commandattribute#targetimmunity). Never empty: a pattern that matches nobody is a usage error before the command runs.
