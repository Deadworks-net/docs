# CommandException

Thrown from a [`CommandAttribute`](/api-reference/commands/commandattribute) handler, or a [`CommandConverters`](/api-reference/commands/commandconverters) parser, to stop the command and send `Exception.Message` to the caller. Nothing is logged: it's an answer, not an error. Any other exception is logged with its stack trace, and the caller only hears that the command failed.
